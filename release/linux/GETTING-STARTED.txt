CHARACTERIZATION - QUICK START GUIDE (Linux)
============================================

Local app for organizing characterization data
(projects -> molecules -> analytics). All data stays on this PC.


FIRST-TIME SETUP (once)
-----------------------
1. Extract the archive to a permanent location, e.g.
       tar -xzf Characterization-*-linux-x86_64.tar.gz -C ~/Applications
2. Run ./create-desktop-shortcut.sh in the extracted folder. It adds
   "Characterization" to your application menu and the desktop.
3. Start the app from the menu (or ./Characterization).

If the window does not open, a few common system libraries may be
missing. On Ubuntu/Debian:
    sudo apt install libxcb-cursor0 libxkbcommon-x11-0 libegl1 libnss3


DAILY USE
---------
- The app opens in its own window. Close the window or click "Quit"
  (top right): a backup is taken and the data folder is released.
- Your data lives in ~/.local/share/Characterization (data/, backups/),
  separate from this program folder; nothing is sent to the internet.


WHAT ONLY WORKS ON WINDOWS
--------------------------
ChemDraw is remote-controlled on Windows only. On Linux:
- Structure images are pasted with Ctrl+V or dragged in as image files,
  but the ChemDraw drawing itself (.cdx) is not captured with them.
- "Copy" (ChemDraw object to the clipboard) and re-rendering a picture
  after editing the .cdx are not available.
- The Word document uses the stored picture of the reaction equation
  instead of an editable ChemDraw object.


INSTALLING A NEW VERSION (without losing data)
----------------------------------------------
1. Close the app.
2. Download the new archive from the Releases page on GitHub.
3. Delete this program folder and extract the new archive in its place.
4. Run ./create-desktop-shortcut.sh again.


PROBLEMS?
---------
Error details: ~/.local/share/Characterization/app.log
