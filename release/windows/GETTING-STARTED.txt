CHARACTERIZATION - QUICK START GUIDE
====================================

Local app for organizing characterization data
(projects -> molecules -> analytics). All data stays on this PC.


FIRST-TIME SETUP (once)
-----------------------
1. Extract the ZIP to a permanent location (e.g. Documents).
   Do not start the program from inside the ZIP, and do not bury
   it too deep in sub-folders (Windows limits path lengths).
2. Double-click "Create desktop shortcut.bat" in this folder -
   this puts a "Characterization" icon on your desktop.
3. Start the app via the desktop icon (or Characterization.exe).
   On the very first start Windows may warn that the program is
   unknown: click "More info" -> "Run anyway".


DAILY USE
---------
- Start via the desktop icon. The app opens in its own window.
- To close the app, close the window or click "Quit" (top right):
  a backup is taken and the data folder is released for other PCs.
- Your data lives in %LOCALAPPDATA%\Characterization (data\,
  backups\) - separate from this program folder, and nothing is
  sent to the internet.


USING THE SAME DATA ON SEVERAL PCs
----------------------------------
1. On the PC with your data: open "Backups" in the app, then
   "Change data folder..." at the bottom, and pick an empty folder
   on a network drive (e.g. H:\...\Characterization-Data). Your
   data is copied there and the app switches to it.
2. On each other PC: install the program as usual, then pick the
   SAME folder in the same dialog. It is opened directly.
Only one PC can edit at a time - the other one shows a yellow
"read-only" banner until the app is closed on the first PC.
Linked files on network drives work on every PC; files on a local
drive (C:\...) are marked with a small PC symbol because other PCs
cannot reach them.


INSTALLING A NEW VERSION (without losing data)
----------------------------------------------
The app looks for new versions on GitHub when it starts and offers
them in a bar at the top. Click "Install update and restart" - it
downloads, checks and installs the new version and starts again.
Your data is not touched. Switch the check off with
"update_check": false in config.json (data folder, see DAILY USE).

By hand:
1. Close the app.
2. Download the new ZIP from the Releases page on GitHub.
3. Delete this program folder and extract the new ZIP in its place.
   Your data is not in this folder, so nothing is lost.
4. If the folder moved: run "Create desktop shortcut.bat" again.

The installed version is shown in the window title and at the top
of the app next to the title.


PROBLEMS?
---------
- The window stays blank or does not open: the Microsoft Edge
  WebView2 runtime is missing (Windows 11 has it built in). The
  app then opens in your browser instead; installing WebView2
  from microsoft.com gives you the window back.
- Error details: %LOCALAPPDATA%\Characterization\app.log
  (updates: update.log in the same folder)
